# HALCYON demo video script

> **Recording status:** This is the original pre-recording shot list. The final
> narrated full playthrough runs 5:38 and is available at
> https://youtu.be/5XmZJRSN-l0.

**Original target runtime:** Under three minutes. Record the page and WebMCP-capable
agent side by side where noted; keep ship audio audible beneath narration.

## 0:00 — Cold open: a dark hull

**Shot:** Fade from black to HALCYON's wake-up console and title. The ship is
dark; the crew status is one awake human and one waiting computer.

**Narration:** “This is HALCYON: a rescue puzzle for two crew members, a human
with hands and an agent that becomes the ship computer.”

## 0:15 — The premise

**Shot:** Show the briefing and the first cooperative instruction.

**Narration:** “Your agent is the ship computer — literally. It discovers and
calls WebMCP tools while you perform the physical tasks it cannot.”

## 0:30 — Chapter 1: Contact

**Shot:** Screen-record the agent and the page side by side. The agent
discovers the boot tools; the human works the breaker to complete the handoff.

**Narration:** “Chapter one teaches tool discovery. Neither a tool call nor a
human click can boot the ship alone.”

## 1:00 — Chapter 2: Manifest

**Shot:** Open a read-only damage briefing, then deliberately show the
`SECTION_UNREACHABLE` coaching error while the human identifies the reachable
section.

**Narration:** “Read-only tools reveal the computer's half of the damage map.
When the agent asks for the wrong section, the ship returns a structured,
in-world coaching error instead of stranding the run.”

## 1:30 — Chapter 4: Antenna

**Shot:** Lock the dish with the human control. Keep the flight recorder open
as new communications tools appear live, then show an obsolete tool disappear.

**Narration:** “The antenna chapter makes dynamic registration visible: the
human's alignment changes which WebMCP tools the agent can use.”

## 2:00 — Chapter 5: Two-Man Rule

**Shot:** Show the agent authorize purge, then the human hold both vent
controls. Include the interlock feedback.

**Narration:** “For a sensitive action, the agent supplies authorization and
the human supplies a two-man physical confirmation. The game keeps both roles
necessary.”

## 2:20 — Chapter 6: Burn replay

**Shot:** Trigger the completed-run replay and scroll the flight-recorder
timeline through tool calls and human milestones to the jump home.

**Narration:** “The final burn is multi-tool orchestration, then a replay that
makes the whole cooperative run legible to a judge.”

## 2:40 — Close

**Shot:** Hold on the jump-home completion state, then fade to the HALCYON
title and repository address.

**Narration:** “Built on WebMCP. Neither of us could have done it alone.”
